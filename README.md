# Damn Vulnerable DeFi — Writeups

[Damn Vulnerable DeFi](https://github.com/theredguild/damn-vulnerable-defi) is the smart contract security playground for developers, security researchers and educators.

It covers flashloans, price oracles, governance, NFTs, DEXs, lending pools, smart contract wallets, timelocks, vaults, meta-transactions, token distributions, upgradeability and more.

This repository contains my solutions for the odd-numbered challenges from a collaborative repo with [Khoi Hoang Xuan](https://github.com/KhoiHoangXuan).
