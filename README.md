# Damn Vulnerable DeFi — Writeups

[Damn Vulnerable DeFi](https://github.com/theredguild/damn-vulnerable-defi) is _the_ smart contract security playground for developers, security researchers and educators.

Perhaps the most sophisticated vulnerable set of Solidity smart contracts ever witnessed, it features flashloans, price oracles, governance, NFTs, DEXs, lending pools, smart contract wallets, timelocks, vaults, meta-transactions, token distributions, upgradeability and more.

My odd-numbered solutions, extracted from a [collaborative repo](https://github.com/KhoiHoangXuan/smart_contract) with [Khoi Hoang Xuan](https://github.com/KhoiHoangXuan).
